# The Missing Rupee 💸

> **Financial Discovery & Anti-Dark Patterns Engine**  
> Uncover recurring subscription commitments, detect sneaky price hikes and trial conversions, and take back control of your recurring debit mandates.

---

## Overview

Modern digital subscriptions frequently rely on obscure billing narratives and sneaky pricing escalations (dark patterns). **The Missing Rupee** is a desktop personal finance dashboard that extracts debit history from a PostgreSQL/Supabase database, passes cryptic transaction strings to Google Gemini to parse and identify recurring commitments, and delivers an actionable interface to track and cancel unwanted debits.

---

## Key Features

- **AI-Powered Descriptor Normalization**: Uses `gemini-3.8-flash` to clean cryptic bank descriptors (e.g., `ACH DEBIT PAYPAL *NETFLIX DIGI` → `Netflix`) and extract category, billing cadence, and latest transaction dates.
- **Anti-Dark Pattern & Anomaly Alerts**:
  - **Price Hikes**: Detects whenever a recurring charge quietly increases (e.g., `₹649 → ₹799 (+23%)`).
  - **Free-Trial Conversions**: Flags when a `₹0` trial converts into a paid recurring billing charge.
  - **New Recurring Debits**: Highlights newly started subscription mandates.
- **Indian Payment Mechanism Detection**: Categorizes debits by payment rail (UPI Autopay, Card recurring, e-Mandate).
- **Guided Cancellation Instructions**: Generates exact, merchant-specific step-by-step navigation instructions to cancel or turn off auto-renew.
- **Financial Health Summary**: Aggregates recurring commitments to estimate overall monthly spend and annualized baseline cost.
- **Offline / Quota Fallback**: Features a built-in mock dataset to keep the desktop interface functional if database connectivity or LLM API calls fail.

## 🗄️ Database Setup & Supabase Configuration

**The Missing Rupee** analyzes raw bank statement debits stored in PostgreSQL via Supabase. The exact database structure is flexible: while a default schema is provided below, you can adapt an existing table as long as your Python data fetcher maps transactions into three core fields: **date**, **description**, and **amount**.

---

### 1. Recommended Table Schema

Run this script in your **Supabase SQL Editor** (`SQL Editor -> New query`) to create the default table:

```sql
-- Create the raw transactions table
CREATE TABLE IF NOT EXISTS transactions (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    transaction_date TIMESTAMP WITH TIME ZONE NOT NULL,
    description TEXT NOT NULL,
    amount NUMERIC(10, 2) NOT NULL,
    transaction_type VARCHAR(20) NOT NULL DEFAULT 'debit',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Index for fast querying by type and date
CREATE INDEX IF NOT EXISTS idx_transactions_type_date 
ON transactions(transaction_type, transaction_date DESC);

```

> **Custom Schema Flexibility:** If your database uses different column names (e.g., `tx_date` or `narration`), update the SQL query in `gemini_analyzer.py` inside `fetch_raw_transactions_from_db()` to alias your columns:
> ```sql
> SELECT tx_date::text AS date, narration AS description, total_amount::float AS amount 
> FROM custom_table 
> WHERE transaction_type = 'debit';
> 
> ```

### 3. Connecting Supabase to `.env`

1. Open your **Supabase Dashboard** --> **Project Settings** --> **Database**.
2. Scroll to **Connection Strings** and choose **Transaction Pooler** (Port `6543`). *Using the pooler endpoint prevents local network IPv6 routing issues.*
3. Copy your URI string and paste it into a `.env` file located in your project root:

```env
# .env

# Supabase Connection String (Transaction Pooler - Port 6543)
DATABASE_URL=postgresql://postgres.[YOUR-PROJECT-REF]:[YOUR-PASSWORD]@[aws-0-region.pooler.supabase.com:6543/postgres](https://aws-0-region.pooler.supabase.com:6543/postgres)

# Google Gemini API Key
GEMINI_API_KEY=your_gemini_api_key_here

```

## Getting Started & Installation

### 1. Prerequisites
- Python 3.10+
- Google Gemini API Key (due to heavy traffic on api keys, sometimes the api doesnt work)

- PostgreSQL / Supabase Database URL[cite: 1, 2]

---

### 2. Clone the Repository
```bash
git clone [https://github.com/](https://github.com/)<your-username>/the-missing-rupee.git
cd the-missing-rupee
```

---

### 3. Install Required Libraries
```bash
pip install customtkinter pillow psycopg2-binary python-dotenv google-genai os datetime
```

---

### 4. Add Your Keys (`.env`)
Create a file named `.env` in the root folder:

```ini
DATABASE_URL="postgresql://<username>:<password>@<host>:<port>/<dbname>"
GEMINI_API_KEY="your-gemini-api-key-here"
```

> **Note**: Ensure the image files (`App Logo.jpeg`, `bell.png`, `profile.png`, `settings.png`) are placed inside the `assets/` folder.

---

### 5. Run the App
```bash
python zamn.py
```
